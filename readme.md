## This repo: deejpotter.com

My business site, with a 3D printing quote-to-order system: customers upload an STL and see a live price from the model's real volume, delivery is priced through Australia Post's API, and orders are paid through Stripe Payment Links. Order statuses then update automatically, with an email to the customer at every step. It also has an admin area, a blog and a few small tools.

**Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, MongoDB Atlas, Clerk, Stripe, Resend, Cloudflare R2, hosted on Render.

To run it: [DEVELOPMENT.md](DEVELOPMENT.md). Why it's built the way it is: [ARCHITECTURE.md](ARCHITECTURE.md).
