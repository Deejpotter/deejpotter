# Hi, I'm Deej 👋

Developer and maker in Frankston, Australia. Former chef, now building web apps, custom tools, and firmware for small hardware projects, plus the 3D printing and CAD work that goes with them.

**Mostly working in:** TypeScript, Next.js, React, Node · C/C++ on ESP32 (PlatformIO, LVGL) · Python for AI agents · self-hosted services with Docker and Coolify.
